Bandyopadhyay-Mehler Hydropathy Plot

Hydropathy scale computed with a centered sliding window

How to use

  1. Paste an amino acid sequence, or one or more sequences in FASTA format (lines starting with >). You can also upload a .fasta file.
  2. Example (PDB ID 2CZS): MVSGEVRTKKVPLDTNHKRFYDA
  3. Set the window size. The original C program uses 3.
  4. Click Get Plot. Each sequence gets a plot and a CSV with CenterPosition, AminoAcid, AverageHydrophobicityScore.

Everything runs in your browser. Your sequences are never uploaded anywhere.
